**Card** — the universal container, Grab-style: white fill, soft 16px radius, floating on a soft ambient shadow (no visible border).

```jsx
<Card>
  <p>Offer content…</p>
</Card>
<Card accent>Active job — green border for emphasis</Card>
```

Pass `accent` for the green-bordered emphasis variant (active job, delivery-code panel). Override anything via `style`.
