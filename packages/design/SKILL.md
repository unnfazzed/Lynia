Read the `readme.md` file within this skill, and explore the other available files (`styles.css` + `tokens/` for the design language, `components/` for the reusable primitives, `ui_kits/` for full-screen product recreations, `guidelines/` for foundation specimens).

If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with the Lynia brand.

Ground rules for staying on-brand: light theme only; Inter (400/600/700 only, self-hosted in assets/fonts/, system-font fallback must look right) with tabular numerals on fares/ETAs/ratings; bright green #00B14F for fills/CTAs only (Button reads --cta-fill so the CTA fill can be re-tuned for contrast without touching the brand accent), dark text-green #006630 for green text and small icons, mint wash #E9F8EF for selected states, gold #F2B705 only for the 'recommended' marker; white cards floating on a soft shadow (16px radius, no visible border); full-pill buttons (one 52px primary CTA per screen); 12px-radius inputs with labels above (Field supports inline error + hint); touch targets ≥ 44px; icons come ONLY from the self-hosted subset assets/lynia-icons.js (~5KB Lucide shim — never load a full icon library) and are always paired with a text label; copy is second-person, sentence-case, calm, and every dead-end offers an action. Hard device rules: design at 320px width first, 16px screen padding, ~150KB per screen, no photos/gradients, skeletons over spinners. To start a new screen, copy templates/app-screen. The Paper Dove (assets/brand/lyniago-mark.svg) + "LyniaGo" in Fredoka 600 (Go in #009D3B, via --font-wordmark) is the single consumer brand across the app, web/ops console, splash, icon and marketing. Lynia Finance is only the background parent company (legal/regulatory entity) — never a customer-facing brand; whenever a mark is shown to a user it is LyniaGo. Creases (the hidden cross) only render at ≥32px; below that use the silhouette. The old "L" monogram tile is retired.

If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.
