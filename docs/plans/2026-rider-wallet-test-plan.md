## Affected Pages/Routes
- Mobile: rider earnings screen — new balance card, ledger history, top-up entry point; must render server-provided rate/floor/balance (never bundled policy), and degrade gracefully offline.
- Mobile: rider online-gate state — new "Top up to keep riding" blocked state; must NEVER appear while commission rate is 0%.
- Mobile: top-up flow (PR2) — amount entry (min $5), EcoCash USSD prompt wait state, success/timeout/retry states.
- Admin: rider detail — wallet balance + ledger view, manual credit form (idempotent), account freeze.
- Admin: commission page — bulk seed-credit action (flip-day grace credits), idempotent on rerun.

## Key Interactions to Verify
- Complete a delivery end-to-end at rate 0%: no ledger rows appear, no balance change, no gate — the pilot experience is untouched (CRITICAL regression).
- In a rate>0 test env: complete delivery → commission debited exactly once (retry the completion request — still one ledger row).
- Admin manual credit with the same idempotency key twice → one credit.
- Below-floor rider (rate>0): cannot go online, sees top-up state; admin credit above floor → gate clears without app restart.
- Fare-adjust on a completed order (rate>0) → old commission reversed, new amount charged; ledger shows both rows.

## Edge Cases
- Rider with no wallet row yet (pre-wallet account) completes a ride — account lazily created, completion never blocked.
- Order with null agreedFare completes — debit skipped, alert raised, no crash.
- Debit larger than balance (5% of a big fare) — balance goes negative, displayed as owed, next top-up nets against it.
- Double-tap on top-up submit — exactly one pending TopUp created.
- Forged/unverified EcoCash callback — rejected, no credit written.
- Late EcoCash confirmation after the top-up expired — credits exactly once.
- Frozen (admin-held) account — top-ups and going online blocked regardless of balance.

## Critical Paths
- Flip-day rehearsal (test env at ratePct 5): bulk seed-credit all riders → complete ride → debit → balance crosses floor → rider gated → top-up (manual credit AND EcoCash sandbox) → gate clears. This entire chain green is the build's definition of done.
- Ride completion (both paths: customer-rates and auto-close) keeps working with wallet tables present — the single most load-bearing flow in the product.
