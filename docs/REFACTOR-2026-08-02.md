## Phase 1 — the work: RF-13, mechanical handler collapse

`apps/merchant/app/components/queue/QueueBoard.tsx` defined ~15 handler functions inside
`QueueBoard`, most sharing the exact shape `async function handleX(...args) { await apiCall(...);
refetch(); }` (`handleMarkReady`, `handleLogCall`, `handleConfirmGoodsReturned`, and — once the
call is separated from its argument-shaping — `handleReject`, `handleRequestPayment`,
`handleConfirmPayment`, `handleReleaseUnpaid`, `handleRefund`, `handleConfirmReturnedCash`,
`handleReportNonReturn`, plus `handleAccept`/`handleHoldResume`/`handleHoldCancel` once their extra
per-call logic is expressed as a small wrapped lambda). Collapsed the repeated body into one
generic `withRefetch<Args>(action, refetch)` helper that awaits the action then calls `refetch()`;
each handler is now a one-line `const handleX = withRefetch(apiFn, refetch)` (or
`withRefetch((args) => apiFn(...), refetch)` where the call needed argument transformation, e.g.
`handleAccept`'s `unavailableDishIds` empty-to-`undefined` mapping, `handleReleaseUnpaid`'s
hardcoded `"other"` reason, `handleRefund`'s body-destructure into positional args).

Left untouched, deliberately, because they don't fit the wrap-and-refetch shape:
`handleRevealPickupCode` (returns a value, no refetch), `handleOpenHold`/`handleHoldDismiss` (no
API call at all). `handleHoldResume`/`handleHoldCancel` keep their extra `setOpenHoldId(null)`
side effect by wrapping a small async lambda that does the dispatch call + state reset, with
`withRefetch` supplying the trailing `refetch()` — same call order as before
(`dispatchResume`/`dispatchCancel` → `setOpenHoldId(null)` → `refetch()`).

Every call site's external behavior — argument list, call order, and the propagate-the-rejection
contract `LC-D03` documented — is unchanged; only the repeated boilerplate moved into the shared
wrapper. No test needed to change: `QueueBoard.test.tsx` already exercises the accept/refetch flow,
the `markReady` rejection-propagation path, and the `revealPickupCode`/`confirmGoodsReturned`
rejection paths, and all four still pass unmodified.
