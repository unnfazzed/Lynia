## Phase 2 — the work: RF-12, cross-file duplication collapse

Confirmed by direct read (not just the survey) that four services in `apps/api/src/merchant/`
carried byte-identical private helpers:

- `ownMerchantId`/`findOwnMerchantIdOrThrow` (same Prisma `merchant.findUnique` + `NotFoundException`
  lookup) in `food-order.service.ts`, `food-dispatch.service.ts`, `food-debt.service.ts`, and
  `merchant.service.ts` (4 copies).
- `notifyQueue` (kitchen-socket best-effort push) in `food-order.service.ts` and
  `food-dispatch.service.ts` (2 copies).
- `isDishOutOfStock`/`isOutOfStock` (same one-line `outOfStockUntil` check) in
  `food-order.service.ts` and `merchant.service.ts` (2 copies).

Extracted all three into a new `apps/api/src/merchant/merchant-lookup.util.ts`. Each class's private
method now delegates in one line to the shared function — **every external method name and signature
stayed byte-identical**, so zero call sites changed; the diff is scoped entirely to the duplicated
method/function bodies. Deliberately did NOT touch `food-dispatch.service.ts`'s actual dispatch
decision logic (`tick`/`acceptDispatch`/`declineDispatch`/`dropDispatch`) — only its non-decision
`ownMerchantId`/`notifyQueue` boilerplate was in scope, confirmed by reading the full method bodies
before editing.
